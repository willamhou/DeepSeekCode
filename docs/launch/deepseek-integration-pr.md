## Longer Description

~~~markdown
DeepSeekCode is a DeepSeek-first terminal coding agent for Linux/macOS local
repository work. It provides a full-screen TUI, line-oriented REPL, and one-shot
`deepseek run` mode for inspecting repositories, editing files, running checks,
reviewing diffs, and resuming local sessions.

Install:

```bash
npm install -g @deepseek-code/cli
deepseek quickstart
```

No-install run:

```bash
npx @deepseek-code/cli quickstart
```

It includes DeepSeek V4 Flash/Pro routing, permissioned file and shell tools,
MCP/ACP surfaces, local runtime sessions, `deepseek stats`, `deepseek events
replay`, `deepseek events diff`, deterministic repair/cache evidence, and
model-backed demo media.

Evidence:

- README interactive 2048 demo generated by a real `deepseek chat` run.
- Runtime repair/cache evidence via `deepseek dogfood repair-cache-evidence`.
- Python/Rust/Node external fixture dogfood evidence.
- Release binaries for Linux x64, Linux arm64, macOS x64, macOS arm64, and
  Windows x64.
~~~
